# 美术指导清单

每首歌出片前，按这份清单做一遍，然后把结论写进 `style.json`。理由写在 `notes` 和 `directives[].note` 里，只写意象，不写歌词原文。

## 1. 看素材

- **配色**：取素材的底色、主色和高光色，分别对应 `palette.bg`、`accent`、`text`、`glow`。
- **构图**：主体在画面哪里？方形封面一般适合开 `background.views`，按段落换取景。
- **边缘**：素材边缘有没有印刷文字（比如专辑名）？有的话要裁掉。现有的取景和遮罩已经避开了方图的上下边缘，换素材后要用样帧再确认一遍。
- **元素**：素材里有哪些可以借用的元素，比如光、羽毛、锁链、几何纹样、花、水？据此决定 `decor` 用哪一套，`particles.feathers` 要不要开。

## 2. 读歌词（用户提供的）

- **情绪曲线**：每一段的情绪是什么，比如压抑、祈愿、爆发、孤独、释怀。
- **意象词**：找出能对应到某种做法的词，比如：
  - 时间、书写、愿望 → 顺序笔画书写
  - 堆积、拼凑 → 乱序笔画拼合、碎片聚合
  - 水、融化、泪 → 水中浮现
  - 消失、结束、孤独 → 碎成光尘
  - 远离、坠落 → 纵深飞入（倒放的感觉）
  - 明快的叙述 → 跟字推镜、遮罩上滑
  - 质问、强调 → 单字特写快切
- **主词**：每句挑一个承载情绪的主词，用 `*词*` 或 `emphasize` 指定。

## 3. 听结构

- **段落强弱**：主歌、副歌、安静段在哪里（看 `analysis.json` 的 `sections` 和能量）。副歌开头就是用招牌招式的地方。
- **节奏快慢**：唱得快的句子，用推得浅、跟得粗的镜头，配快切；唱得慢、拖长音的句子，用缓推，配水中浮现、笔画拼接。
- **高潮点**（`peak`）只用一次 RGB 爆发。

## 4. 定方案

- 写 `directives`：先定下用户点名的位置和意象明确的句子，其余交给编排器自动分配。
- 跑一遍 `lv plan` 检查：
  - 招牌效果在一分钟内是否只用了一次；
  - 相邻两句有没有用同一种做法；
  - 背景有没有在短时间内撞车。
- 出 3 到 4 张样帧给用户确认方向，再出成片。

## 5. 出片前自查

- 字够不够大，能不能一眼看出这句的重点？
- 每句字出完后，有没有停留时间让人读完？
- 镜头是不是一直在动？句与句之间是不是全是硬切？
- 有没有出现用户明确不喜欢的效果（见 AGENTS.md 第 3 节）？
