# 效果目录

每类都有演示画面，在 `npm run studio` 里打开，或者用 `npx remotion render engine/index.ts <Demo名> out/x.mp4 --public-dir=assets` 渲染出来看。

## 整句逐字浮现（mode）

每个字在它唱到的时间出现。镜头路线由 `engine/director/lines.ts` 规划。

| mode | 名称 | 效果 | 镜头 | 用量上限 |
|---|---|---|---|---|
| `follow` | 跟字推镜 | 柔和浮现，可选句末风吹散 | 推近后从左到右跟着字走，唱完拉回整句并停留 | 2 次/分钟 |
| `tate` | 直书下摇 | 日文正立直书 | 从上往下跟字，最后拉回 | 2 次/分钟（仅日文） |
| `water` | 水中浮现 | 字从水线下浮上来，带水波扭曲、涟漪、倒影 | 缓推缓拉 | **1 次/分钟** |
| `cursor` | 光标显字 | 发光光标按唱的节奏移动，字跟在它后面显出 | 跟着光标走 | **1 次/分钟** |
| `strokes` | 笔画拼接 | KanjiVG 真实笔顺，可按顺序书写或乱序飞入拼合 | 缓推 | 2 次/分钟（仅日文） |
| `dust` | 碎成光尘 | 整句亮起后，从一侧碎成光尘上飘 | 缓推 | **1 次/分钟** |
| `shatter` | 碎片聚合 | 每个字切成碎片，从四面八方飞来拼合 | 缓推 | **1 次/分钟** |
| `depth` | 纵深飞入 | 字从画面深处飞向镜头，景深由虚到实 | 缓推 | 2 次/分钟 |
| `maskslide` | 遮罩上滑 | 词从基线后滑上来，整句斜切错位后对齐 | 横移 | 2 次/分钟 |
| `punch` | 单字特写快切 | 跟着拍子，一个字一个字全屏闪现，最后切回整句 | 固定在屏幕上，不跟镜头推拉 | **1 次/分钟** |
| `layout` | 排版模板 | 杂志式大小字组合，主词使用 14 种词入场之一 | 慢呼吸 | 间隔不少于 6 秒，作为兜底 |

- 整句浮现都用**杂志式层级**排版：一个巨大主词，配若干小词，再加一个空心回声字。需要按阅读顺序排一行的方式例外：光标、笔画、遮罩上滑、快切。

| 名称 | 效果 |
|---|---|
| `none` | 留白 |
| `streak` | 光带扫过 |
| `trail` | 星点沿外框走一圈 |

## 背景处理（backdrop，基本每句换一种）

| 名称 | 效果 |
|---|---|
| `drift` | 漂移 |
| `pan` | 在局部细节之间游走 |
| `tilt` | 3D 透视视差 |
| `mirror` | 镜像万花筒 |
| `void` | 留黑 |
| `zoomburst` | 变焦冲击 |
| `duotone` | 双色调 |
| `frame` | 画中画 |
| `strips` | 竖条错动 |

- 外观相近的几种归为同族：`pan`、`frame`、`tilt` 都属于"局部特写"一族，同族 3 句之内不连用。
- 同一种处理在 6 句之内不重复。

| `whip` | 甩镜 | 句与句之间轮换 |
| `pullout` | 拉远换构图 | 句与句之间轮换 |
| `flash` | 闪白 | 副歌开头 |

句与句之间的转场，同一种不连着用两次。

## 全局层

- **镜头**：100% 到 108% 的慢呼吸，加微漂移。
- **鼓点**：底鼓时推镜、背景变亮；军鼓时抖动；镲让粒子闪烁。
- **画面质感**：胶片颗粒、暗角、景深（切镜时背景先虚后实）、飘落的羽毛和灰尘、角落的细线界面装饰。
- **高潮点**：全曲能量最高的地方放一次 RGB 爆发。
